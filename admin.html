📸 Gallery Photos

📸 Как добавить фото:
1. Откройте папку photos на GitHub
2. Нажмите кнопку Add file → Upload files
3. Перетащите ваше фото в окно загрузки
4. Нажмите Commit changes внизу страницы
5. Через ~30 секунд фото появится на сайте автоматически

✅ Как обновить сайт

  1. Нажмите 💾 Save & Download — скачается новый data.json
  2. Откройте GitHub: github.com/aevenko/kirill-chess
  3. Нажмите на файл data.json → кнопка редактирования ✏️ → вставьте содержимое нового файла
  4. Нажмите Commit changes — сайт обновится автоматически через ~30 секунд

📸 Для фото: зайдите в папку photos/ на GitHub → кнопка + → Upload files → перетащите фото → Commit changes

🚀 Опубликовать изменения

После того как нажали 💾 Сохранить и Скачать — скачанный data.json (и фото, если добавляли) нужно положить в папку kirill-chess. Потом нажмите кнопку ниже.

🚀 Открыть Vercel Dashboard

🚀 Открыть GitHub

Все обновления сайта делаются через GitHub. Нажмите кнопку ниже:

📁 Открыть GitHub репозиторий
Как это работает:
1. Обновите файл на GitHub (data.json или фото)
2. Нажмите Commit changes
3. Vercel автоматически задеплоит изменения за ~30 секунд ✅
